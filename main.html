HTML fue ideado por Tim Berners-Lee, un físico británico que trabajaba en el CERN, a finales de la década de 1980, con el objetivo de facilitar el intercambio de información científica mediante un sistema de hipertexto. En 1991, Berners-Lee publicó el primer documento formal llamado HTML Tags, que contenía un conjunto inicial de etiquetas para crear páginas web simples con encabezados, párrafos, listas e hipervínculos. Este lenguaje se basaba en SGML (Standard Generalized Markup Language) y permitió que los documentos fueran accesibles en cualquier computadora, sentando las bases de la web moderna.

Evolución y estandarización

La primera versión informal, HTML 1.0, apareció alrededor de 1993 y ofrecía funcionalidades básicas para crear páginas estáticas. En 1995, el IETF publicó HTML 2.0, la primera especificación oficial que consolidó los principios fundamentales del lenguaje. Posteriormente, el W3C (World Wide Web Consortium) asumió la estandarización de HTML, publicando versiones como HTML 3.2 en 1997 y HTML 4.0 en 1998, incorporando mejoras significativas como hojas de estilo CSS, scripts, tablas complejas y mayor accesibilidad.

  • Multimedia Nativa (Adiós, Plugins)
  • Semántica para Humanos y Máquinas

  • Gráficos y Efectos Visuales

    2. <article>: The Independent Story.
    3. <section>: The Thematic Chapter

HTML en la actualidad (una cita)

Actualmente, la historia de HTML ha llevado a este lenguaje a estar vinculado a JavaScript y CSS3, en lo que la W3C ha denominado Plataforma Web Abierta, que permite que estos lenguajes puedan usarse en el desarrollo de aplicaciones multiplataforma, es decir, tanto en iOS o Windows como Linux o Android.

En cuanto a la versión más reciente de HTML, no olvides que se trata de HTML 5.3, que se emitió en el año 2021, pero sin duda experimentaremos más y más actualizaciones a lo largo de los años. Sobre todo porque tanto la W3C como la WHATWG continúan realizando un arduo trabajo para establecer las recomendaciones y cambios pertinentes. Una cita sin parrafo nuevo
