Historia de HTML

HTML fue ideado por Tim Berners-Lee, un físico británico que trabajaba en el CERN, a finales de la década de 1980, con el objetivo de facilitar el intercambio de información científica mediante un sistema de hipertexto. En 1991, Berners-Lee publicó el primer documento formal llamado HTML Tags, que contenía un conjunto inicial de etiquetas para crear páginas web simples con encabezados, párrafos, listas e hipervínculos. Este lenguaje se basaba en SGML (Standard Generalized Markup Language) y permitió que los documentos fueran accesibles en cualquier computadora, sentando las bases de la web moderna.

Ventajas de HTML5

  • Multimedia Nativa (Adiós, Plugins)
  • Semántica para Humanos y Máquinas
  • Almacenamiento Local (Local Storage)
  • Gráficos y Efectos Visuales
